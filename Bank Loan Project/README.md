Bank Loan Analysis Dashboard (SQL + Excel)

## Project Overview
This project analyzes bank loan applications to evaluate loan performance, borrower behavior, and financial risk. Using Oracle SQL for data preparation and Excel for visualization, the dashboard transforms raw loan data into actionable business insights through KPIs and interactive analytics.

## Objectives
- Monitor loan volume and trends over time
- Evaluate repayment performance (Good vs Bad loans)
- Analyze borrower profiles by region, home ownership, purpose, and employment length
- Track financial indicators such as interest rate and debt-to-income ratio (DTI)
- Provide interactive dashboards for month-to-date and historical comparisons

 ## KPI Metrics & Result
 - Total Loan Applications | 38,576 | Overall demand volume
 - Month-to-Date (MTD) Applications | 4,314 | Current month performance
 - Previous Month-to-Date (PMTD)| 4,035 | Benchmark for growth tracking
 - Total Loan Amount (₹) | 53,981,425 | Portfolio size
 - Average Interest Rate (%) | 12.05 | Borrower cost of credit
 - Average DTI (%) | 13.33 | Borrower repayment capacity
 - Good Loan Percentage | 86.18% | Strong repayment base
 - Bad Loan Percentage | 13.82% | Risk area for credit tightening
   Insight: Month-to-date applications improved compared to the previous month (4,314 vs 4,035), showing positive growth momentum.

## Business Impact
- Risk Management: Identified 13.82% of loans as high-risk → supports tighter credit evaluation.
- Customer Segmentation: Regional, home ownership, and purpose analysis → enables targeted lending strategies.
- Performance Monitoring: Month-to-date vs previous month KPIs → helps track operational efficiency.
- Portfolio Optimization: Good vs Bad loan ratios → guide loan approval and collection strategies.

## Dashboard Highlights
- KPIs for loan applications, amounts, and payments
- Comparative metrics (Current MTD vs Previous MTD)
- Regional analysis by State
- Distribution by Home Ownership and Purpose
- Borrower segmentation by Employment Length
- Interactive slicers and charts for quick filtering

## Tools & Technologies Used
- Oracle SQL Developer → Data cleaning, aggregation, KPI calculation
- Excel → Dashboard creation and visualization
- Pivot Tables & Charts → Dynamic summaries and filtering
- Power Query → Automated data refresh and integration

##  Analyst Workflow
- Data Preparation (SQL): Cleaned raw loan data, calculated KPIs (loan volume, payments, interest rate, DTI, good vs bad ratios).
- Segmentation: Grouped loans by borrower attributes (region, home ownership, purpose, employment length).
- Visualization (Excel): Built interactive dashboard with KPIs, comparative metrics, and slicers for stakeholder use.

## Key Insights
- 86.18% of loans are classified as Good Loans, indicating strong repayment behavior.
- 13.82% are Bad Loans, highlighting risk areas for stricter credit checks.
- Average interest rate is 12.05%, with DTI at 13.33%, showing moderate borrower repayment capacity.
- Loan demand varies significantly by region, purpose, and home ownership, guiding targeted strategies.
